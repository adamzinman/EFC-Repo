## Overview

A small modal popup that tells the user a command was refused because their access level is too low. It writes nothing and reads no tag.

- **Default size:** 360 x 170 (`props.defaultSize`).
- **Popup settings (set by `efc.ui.denied`):** id `efcAccessDenied`, title `Invalid access level`, `modal=True`, `showCloseIcon=True`, `overlayDismiss=True`. The user can leave through OK, the close icon or a click outside the popup.
- **Parameters:** `action` (what was refused), `need` (the role name required), `have` (the user's role name) and `user` (the user name, or empty when not signed in).
- **Generated view:** yes, `access_denied()` in `generator/docks/build_docks.py`.

## How it operates

**Title.** A fixed label, `Invalid access level` (`Text/Subheader`).

**Message.** One expression label: `<action> requires <need> access or higher.` For a command button the action is `<tag name> <member>`, for example `XV101 Cmd_Open`. Other actions are `<tag name> ACK`, `<tag name> double-tap command` and `Unbypass <n>`.

**Who.** A caption: `Signed in as <user> (<have>).`, or `Not signed in (<have>).` when `user` is empty.

**Note.** A fixed caption, `Nothing was written.`

**OK.** Closes the popup `efcAccessDenied`.

Why it appears. Command buttons below the user's level stay visible and pressable, with a lock icon and a `Requires <role> access` tooltip. A press goes to `efc.ui`, which compares the user's level with the level the button needs, refuses the write, logs `Refused <action> for <user> (<have>): needs <need>` at WARN level on the `efc.ui` logger, and opens this popup. Release events (for example the jog buttons on release) pass `notify=False` and are refused without a popup.

## Notes and open questions

1. **Only the refusal is shown.** The popup does not say how to get a higher level. That is a gateway security matter.
2. **Names depend on `efc.ui.ROLE_ALIASES`.** `have` is the library role name (`Guest` to `Admin`) after matching the user's security levels case-insensitively. A site role name that is not in `ROLES` or `ROLE_ALIASES` counts as Guest.
3. **Not shown for every refusal.** `efc.ui.bypass` returns False without a popup (its BYPASS button is enabled only for Supervisor and above). Jog release events are refused silently.
