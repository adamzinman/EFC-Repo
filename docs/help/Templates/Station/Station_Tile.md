# Station overview tile

Covers `Templates/Station/Station_Tile`.
Source: `projects/EFC_Library/com.inductiveautomation.perspective/views/Templates/Station/Station_Tile/view.json` (same content as the copy in `imported/EFC_StationFaceplates/`).
Dynamic window it opens: `Templates/Dynamic Window/Station/Station` (see [Templates/Dynamic Window/Station/Station](../Dynamic%20Window/Station/Station.md)).
Related template: [Station_Fill](Station_Fill.md).

## Overview

A one-station overview tile for a T_Station instance. It shows the station name, scale, state word, net and target weight, a fill bar with a target marker, the vessel pressure and the percent of target. A click opens the station dock. The tile has no buttons and writes no tags.

- **Default size:** 220 x 96 (`props.defaultSize`).
- **Bound to:** one T_Station instance through `params.tagPath`.
- **Opening the dock:** a single click on the tile runs `efc.ui.openDynamic(self)`. `openDynamic` maps `tType` (default `T_Station`) through `BY_TYPE` to `dw_Station`, and `WINDOWS` maps that to `Templates/Dynamic Window/Station/Station`. It then loads `Templates/Dynamic Window/Station/Station` into the page's `dw_Right` dock with params `{tagPath: ...}` (`system.perspective.alterDock`) and opens the dock. Only `tagPath` is passed on, unless `dwTagPath` is set, in which case that value is used instead.
- **Dock source:** `Templates/Dynamic Window/Station/Station` is not generated by `generator/docks/build_docks.py`. It is the imported `Station_Sidebar` view, which `build.py` (`RELOCATE`) moves to `Templates/Dynamic Window/Station/Station` when it merges the library. The two copies are the same apart from the path.
- **Embedded views:** none. This view has no `ia.display.view` component.
- **Where it is used:** `Templates/Station/_Demo` places four instances (`[default]Station_Demo/Station_1` to `Station_4`) with `tagPath` set, next to the four `Station_Fill` instances.

## How it operates

**State word and colour.** The `s` transform (see Scripts reference) takes the first true condition in this order: Disabled, Failed, Complete, Filling, SampleCMD, Vacuuming, Venting, Recovering, Active, then ReadyToStart or ReadyToFill. If none is true the word is IDLE. The chip class is the state colour plus `Station/Fill/Chip`.

| Word | Chip class | Condition (custom.t key) |
|---|---|---|
| DISABLED | State/OutOfService | Disabled |
| FAULT | State/Fault | Failed |
| COMPLETE | State/Stopped | Complete |
| FILLING | State/Running | Filling |
| SAMPLING | State/Running | SampleCMD |
| VACUUMING | State/Transition | Vacuuming |
| VENTING | State/Transition | Venting |
| RECOVERING | State/Transition | Recovering |
| ACTIVE | State/Running | Active |
| READY | State/Stopped | ReadyToStart or ReadyToFill |
| IDLE | State/Stopped | none of the above |

**Weights and fill bar.** The net and target values come from `NetWeight` and `TargetWeight`, both shown with 3 decimals. The bar length is net / (target x 1.08), clamped to 0 to 1. The target marker sits at target / (target x 1.08). When the target is 0 or less, the bar scale is 1.0 (see Notes).

**Over-fill.** When the target is above 0 and net is above target + `Deadband`, the percent text starts with `OVER` and the bar uses `Bar/FillAlarm`. Otherwise it uses `Bar/Fill`.

**Percent.** `pct` is net / target x 100, shown to 1 decimal place, or `-` when the target is 0 or less.

**Pressure.** `pt` is `Val_PT` to 1 decimal place with thousands separators. It shows `-----` when `Inp_PTValid` is false. The tile binds only the text, so no bad-quality class is applied.

**Name, scale and units.** The name is `Cfg_Desc`, or `Station` when it is empty. The scale is `Cfg_ScaleName`, or empty. The units are `Cfg_EU`, or `kg` when that is empty, `---`, `null` or `None`. The `psig` label on the pressure line is fixed text.

**Selected.** When `Sts_Selected` is true, the root adds `Util/Highlight`.

**Tooltip.** The root tooltip reads "Open station faceplate". It is static text.

**Commands and security.** The tile has no command buttons and writes no tags. The click opens the dock, and that is the only action. No role level is checked and no audit record is written by this view. Commands are made from the dock, not from the tile.

## Scripts reference

Total: **1 event script** and **1 transform script**. There are no custom methods, message handlers or property-change scripts.

1. **`root`**: `events.dom.onClick` on `root`, scope G. Trigger: a single click on the tile. It opens the station dock. Code:

```python
	# Opens the dw_Station dynamic window in the page's right dock dw_Right (efc.ui, decision 31).
	efc.ui.openDynamic(self)
```

   The code calls `efc.ui.openDynamic(self)`, which opens `Templates/Dynamic Window/Station/Station` in the page's `dw_Right` dock.

2. **`view.custom.s`**: script transform on the property binding from `view.custom.t`. Trigger: runs whenever any of the 20 mirrored values changes. It returns the whole display dict. Code:

```python
	t = value
	def g(k, d=None):
		try:
			v = t[k]
		except:
			v = None
		return d if v is None else v
	def b(k):
		try:
			return bool(g(k, False))
		except:
			return False
	def f(k):
		try:
			return float(g(k, 0.0))
		except:
			return 0.0
	def cl(x):
		return max(0.0, min(1.0, x))
	f3 = lambda x: "%.3f" % x
	def f1(x):
		return "{:,.1f}".format(x)
	dis, flt, cmp = b("Disabled"), b("Failed"), b("Complete")
	smp = b("SampleCMD")
	if dis:   word, chip, txt = "DISABLED", "State/OutOfService", "Station disabled"
	elif flt: word, chip, txt = "FAULT", "State/Fault", "Station fault"
	elif cmp: word, chip, txt = "COMPLETE", "State/Stopped", "Fill complete"
	elif b("Filling"):    word, chip, txt = "FILLING", "State/Running", "Filling primary vessel"
	elif smp:             word, chip, txt = "SAMPLING", "State/Running", "Routing sample to secondary"
	elif b("Vacuuming"):  word, chip, txt = "VACUUMING", "State/Transition", "Evacuating vessel"
	elif b("Venting"):    word, chip, txt = "VENTING", "State/Transition", "Venting"
	elif b("Recovering"): word, chip, txt = "RECOVERING", "State/Transition", "Recovering"
	elif b("Active"):     word, chip, txt = "ACTIVE", "State/Running", "Station active"
	elif b("ReadyToStart") or b("ReadyToFill"): word, chip, txt = "READY", "State/Stopped", "Ready to start"
	else:                 word, chip, txt = "IDLE", "State/Stopped", "Idle"
	busy = chip in ("State/Running", "State/Transition")
	msg = g("Msg", "")
	try:
		msg = msg.strip() if isinstance(msg, basestring) else ""
	except NameError:
		msg = msg.strip() if isinstance(msg, str) else ""
	if not msg:
		msg = txt
	u = g("Units", "")
	u = ("%s" % u).strip() if u is not None else ""
	if u in ("", "---", "null", "None"):
		u = "kg"
	net, tgt, db = f("NetWeight"), f("TargetWeight"), f("Deadband")
	scale = tgt * 1.08 if tgt > 0 else 1.0
	pct = net / tgt * 100.0 if tgt > 0 else 0.0
	over = tgt > 0 and net > tgt + db
	pt, pmax, pre = f("PT"), f("Press_Max"), f("SamplePress")
	ptok = b("PT_Valid")
	pscale = pmax * 1.1 if pmax > 0 else 100.0
	vac = b("Vacuumed")
	st = [0, 0, 0, 0, 0, 0]
	st[0] = 2 if b("Vessel_Present") else 0
	st[1] = 2 if vac else (1 if b("Vacuuming") else 0)
	st[2] = 2 if b("Press_Balanced") else (1 if (b("Active") and vac and not b("Filling")) else 0)
	st[3] = 2 if (cmp or smp) else (1 if b("Filling") else 0)
	st[4] = 2 if cmp else (1 if smp else 0)
	st[5] = 2 if cmp else 0
	if dis:
		st = [0, 0, 0, 0, 0, 0]
	elif flt:
		for i in range(6):
			if st[i] != 2:
				st[i] = 3
				break
	SC = ["Station/Step/Pending", "Station/Step/Active", "Station/Step/Done", "Station/Step/Fault"]
	TC = ["Text/Caption Text/Mod/Center", "Text/Caption Text/Mod/Center Text/Color/Default Text/Weight/Bold",
	      "Text/Caption Text/Mod/Center Text/Color/Default", "Text/Caption Text/Mod/Center Text/Color/Default Text/Weight/Bold"]
	led = lambda x: "Indicator/LED/On" if x else "Indicator/LED/Off"
	pl = lambda x: "Text/Label Text/Color/Default" if x else "Text/Label"
	sel = b("Selected")
	tz = busy or dis
	rs = not (cmp or flt)
	foot = "Station disabled: commands unavailable" if dis else ("Tare and Zero locked while active" if tz else "")
	name = g("StationName", "")
	scl = g("ScaleName", "")
	return {
		"name": ("%s" % name) if name else "Station", "scale": ("%s" % scl) if scl else "",
		"word": word, "chip": chip, "msg": msg, "units": u,
		"busy": busy, "dis": dis, "sel": sel,
		"selText": "SELECTED" if sel else "SELECT",
		"selCls": "Button/Toggle/On" if sel else "Button/Toggle/Off",
		"hiCls": " Util/Highlight" if sel else "",
		"net": f3(net), "target": f3(tgt), "rem": f3(max(0.0, tgt - net)), "db": f3(db),
		"gross": f3(f("GrossWeight")), "tare": f3(f("TareWeight")), "total": f3(f("TotalWeight")),
		"pct": (("OVER " if over else "") + "%.1f%%" % pct) if tgt > 0 else "-",
		"fillCls": "Bar/FillAlarm" if over else "Bar/Fill",
		"fillW": cl(net / scale), "tgtX": cl(tgt / scale) if tgt > 0 else 0.0,
		"dbX": cl((tgt - db) / scale), "dbW": max(0.012, cl(2 * db / scale)) if tgt > 0 else 0.0,
		"pt": f1(pt) if ptok else "-----", "ptBad": not ptok,
		"ptCls": "Text/ValueLarge" if ptok else "Text/ValueLarge Value/BadQuality",
		"ptSmallCls": "Text/Value Text/Mod/Right" if ptok else "Text/Value Text/Mod/Right Value/BadQuality",
		"ptd": "dP %.1f psi" % f("PT_Diff"),
		"ptW": cl(pt / pscale) if ptok else 0.0,
		"preX": cl(pre / pscale), "maxX": cl(pmax / pscale - 0.008),
		"pre": f1(pre), "pmax": f1(pmax),
		"steps": [SC[x] for x in st], "stepText": [TC[x] for x in st],
		"permLed": [led(b("Vessel_Present")), led(ptok), led(b("Press_Balanced")), led(b("ReadyToStart")), led(b("ReadyToFill"))],
		"permTxt": [pl(b("Vessel_Present")), pl(ptok), pl(b("Press_Balanced")), pl(b("ReadyToStart")), pl(b("ReadyToFill"))],
		"inReq": led(b("InletREQ")), "inCmd": led(b("InletCMD")), "inIlk": b("InletREQ") and not b("InletCMD"),
		"smReq": led(b("SampleREQ")), "smCmd": led(smp), "smIlk": b("SampleREQ") and not smp,
		"vaReq": led(b("VacuumREQ")), "vaCmd": led(b("VacuumCMD")), "vaIlk": b("VacuumREQ") and not b("VacuumCMD"),
		"tzLocked": tz, "resetLocked": rs, "foot": foot
	}
```

   Plain-language summary:
   - Reads each key with `g()`, `b()` and `f()`. These return a default when the key is missing or `None`: 0 for numbers, false for booleans and empty for text.
   - Sets the state word and chip from the priority list in How it operates.
   - Builds the net, target, remaining, percent and over-fill values. `rem` is target - net, and `over` is true when target > 0 and net > target + deadband.
   - Builds the bar and marker positions, using a 1.08 x target scale.
   - Builds the pressure text, which is `-----` when `PT_Valid` is false.
   - Builds the units text, with `kg` as the fallback.
   - Computes step, permissive and valve-request fields. The tile binds none of them (see Notes).

### library calls made from this view

- **`efc.ui.openDynamic(component)`** (`projects/EFC_Library/ignition/script-python/efc/ui/code.py`): picks the window from `dockId`, or from `BY_TYPE[tType]` when `dockId` is empty. If the window is not in `WINDOWS`, it logs a warning and stops. Otherwise it takes the tag path from `dwTagPath`, then `tagPath`, then `cardPath`, and loads `Templates/Dynamic Window/Station/Station` into the `dw_Right` dock with `params: {tagPath: <that path>}`, then opens the dock. It passes `model` only if the caller sets it, and this view has no such param. It does not check the role level, write any tag or write an audit record.

## Notes and open questions

- **Inputs the transform reads but the tile does not mirror.** 15 keys are read by the transform but are not in `custom.t`: GrossWeight, TareWeight, TotalWeight, Msg, PT_Diff, Press_Max, SamplePress, Press_Balanced, Vacuumed, Vessel_Present, InletREQ, InletCMD, SampleREQ, VacuumREQ and VacuumCMD. They default to 0, false or empty. The tile shows no value they drive, so nothing wrong is visible today. The transform still computes 38 keys that the tile never binds. Any future tile field that uses one of the 15 would show the default silently.
- **Pressure quality style.** The transform provides `ptCls` and `ptSmallCls` for bad quality, but the tile binds only the text of `Pt`. A bad pressure reading shows `-----` with no bad-quality style.
- **Target of 0 or less.** The bar scale falls back to 1.0 (`scale = tgt * 1.08 if tgt > 0 else 1.0`). So any net of 1.0 or more fills the bar, whatever the units. Whether the bar should be hidden in that case is not defined in the repo.
- **Fixed units text.** The pressure unit `psig` is fixed in the view. The weight fallback `kg` is used when `Cfg_EU` is empty, even though the PCLib comment lists `kg, lb`.
- **Naming.** `docs/station-faceplates.md` calls the instance type `DDT_Station`. The PCLib type and the `efc.ui` mapping use `T_Station`.
