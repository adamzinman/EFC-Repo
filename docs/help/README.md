# EFC Library help

There is one help file per template family and per dynamic window. Each one covers how the view operates, its params and custom properties, every binding and script, the tag members it uses, and its component tree.

Help files sit at the same path as the view under `projects/EFC_Library/com.inductiveautomation.perspective/views/`. A family of views with identical properties (differing only in symbol geometry) shares one file.
