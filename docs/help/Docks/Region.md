Source: `projects/EFC_Library/com.inductiveautomation.perspective/views/Docks/Region/view.json`
Library code: `projects/EFC_Library/ignition/script-python/efc/ui/code.py` (`region`, `setDefaultDock`, `openDynamic`, `closeDynamic`)
Generated by `generator/docks/build_docks.py` (`region()`). Change the generator, not `view.json`.
Used by: every screen, placed in the screen's right-hand region. Dynamic windows open into it: [ValveDiscrete](../Templates/Dynamic%20Window/Valves/ValveDiscrete.md) and the other `Templates/Dynamic Window/*` windows, through `efc.ui.openDynamic`. [IOCard](../Templates/Dynamic%20Window/IO/IOCard.md) is one of them.

## Overview

The screen's right-hand host. `Docks/Region` is an embedded view with one child, `Window`. What `Window` shows (its view path and params) comes from `session.custom.efcDw[<pageId>]`, so each page keeps its own dock. Templates open a dynamic window by writing that value. The close button of a window writes back the screen's default view.

- **Default size:** 400 x 860 (`props.defaultSize`). The child `Window` uses neither the default width nor the default height, so it fills the region the screen gives it.
- **Parameters:** `defaultDock` (the view path shown when the page starts) and `defaultParams` (the params for that view).
- **Opened:** it is not opened. The screen places it, and it then shows whatever the session state says.
- **Generated view:** yes, `region()` in `generator/docks/build_docks.py`.

### Placing it on a screen

The screens are not in this library. No view in `projects/EFC_Library` embeds `Docks/Region`, so the placement below is what `code.py` and the generator require, not something checked in this repository.

1. Put one `Docks/Region` embedded view in the screen's right-hand region, one per screen. The generator's comment says "Put one on each screen".
2. Set `defaultDock` to the view path that the screen should show when nothing is open (for example, the screen's overview view). The default is held in the session, so it survives an open window being replaced.
3. Set `defaultParams` to the params that default view needs. Leave it empty (`{}`) if it needs none.
4. Nothing to set for the page id. The state is keyed on `page.props.pageId`, which Perspective assigns to each page, so two pages in the same session do not share a dock.

If `defaultDock` is empty, `setDefaultDock` writes nothing at startup. The region then shows whatever `session.custom.efcDw[<pageId>]` already holds, which is blank for a new page. See the Notes for the close behaviour in that case.

## How it operates

**Startup.** The root's `system.onStartup` event runs `efc.ui.setDefaultDock(self, defaultDock, defaultParams)`. If `defaultDock` is not empty, `setDefaultDock` records `{path, params}` as the page's `default` and also sets the current `path` and `params` to the same values. Because it writes both, each start of this view resets the region to the default. An open window is replaced by the default if the Region is recreated, for example after a page change that remounts it.

**Display.** `custom.dw` is bound to `session.custom.efcDw` through the transform `efc.ui.region(value, self.page.props.pageId)`. That transform returns `{'path': ..., 'params': ...}` for this page, or blank values if the page has no entry. `Window` binds `props.path` to `dw.path` and `props.params` to `dw.params`, through two small transforms. When the path is blank, `Window` shows nothing.

**Opening a window.** A template's single click runs `efc.ui.openDynamic(self)`. It picks the window from `dockId` or `tType`, takes the tag path from `dwTagPath`, `tagPath` or `cardPath`, and calls `_write`, which sets `path` and `params` for this page. `default` is kept, so a close can still return to the screen default.

**Closing.** The close button in a window runs `efc.ui.closeDynamic(self)`. It writes the page's `default.path` and `default.params` back as the current `path` and `params`. If there is no `default` (no `defaultDock` was set), the path is written as blank and the region empties.

**State.** `session.custom.efcDw` is a dict keyed by page id. Each value is a dict with `path`, `params` and, after startup, `default`. Writes build a new dict and assign it to `session.custom.efcDw`, so the binding sees the change. Entries are not removed when a page closes.

## Properties reference

### View parameters (`params`)

| Name | Direction | Default | Meaning | Set / read by |
|---|---|---|---|---|
| `defaultDock` | input | `""` | View path shown in the region at page startup (for example `Docks/...`). Empty means nothing is recorded at startup. | Set by the screen; read by `root` `onStartup` (`efc.ui.setDefaultDock`) |
| `defaultParams` | input | `{}` | Params for the default view. Stored with the default and used for the current view. | Set by the screen; read by `efc.ui.setDefaultDock` |

Both params have `paramDirection: input` and `persistent: true`. There are no output params.

### View-level custom properties (`custom`)

| Path | Default | Binding | Source | What it holds / drives |
|---|---|---|---|---|
| `view.custom.dw` | `{"path": "", "params": {}}` | property, transform `return efc.ui.region(value, self.page.props.pageId)` | `session.custom.efcDw` | The path and params the region shows for this page. Drives `Window` (`props.path`, `props.params`). |

### Component-level custom properties

None. The components carry no `custom` properties.

### Session, page and message payloads

- **Reads and writes `session.custom.efcDw`.** A dict keyed by `page.props.pageId`. Each value is `{path, params}`, plus `default` = `{path, params}` once the screen's default is set. Only the `efc.ui` functions write it: `openDynamic`, `setDefaultDock` and `closeDynamic`.
- **Reads `self.page.props.pageId`** in the transform and `component.page.props.pageId` in the functions.
- No message handler, no `page.*` value other than `pageId`, and no `session.props` value.

## Scripts reference

Total: **1 event script** (`system.onStartup`) and **3 transform scripts**. The generator reports 1 because it counts event scripts only. No `customMethods`, `messageHandlers`, property-change scripts or `view.scripts`.

1. **`root`**: `system.onStartup`.
   ```python
   efc.ui.setDefaultDock(self, self.view.params.defaultDock, self.view.params.defaultParams)
   ```
   Records and shows the screen's default view when the page starts. It writes nothing if `defaultDock` is empty.

2. **`view custom.dw`**: transform on the binding.
   ```python
   return efc.ui.region(value, self.page.props.pageId)
   ```
   Returns this page's `{path, params}` from `session.custom.efcDw`.

3. **`root/Window` `props.path`**: transform.
   ```python
   return (value or {}).get('path') or ''
   ```

4. **`root/Window` `props.params`**: transform.
   ```python
   return dict((value or {}).get('params') or {})
   ```

### Library functions called by this view (`efc.ui`, `projects/EFC_Library/ignition/script-python/efc/ui/code.py`)

- **`efc.ui.region(value, pageId)`**: returns `{'path', 'params'}` for `pageId`. Blank if the page has no entry or the value is not a dict. It writes nothing.
- **`efc.ui.setDefaultDock(component, viewPath, params)`**: if `viewPath` is not empty, writes `default = {path: viewPath, params}` and `path = viewPath`, `params = params`, for this page. No role check, no audit, no tag write.
- **`efc.ui.openDynamic(component)`** (called by templates): writes `path` and `params` for this page, keeping `default`. Adds `model` to params when the caller has one. Writes a warning and stops if no window is found for the `dockId` or `tType`.
- **`efc.ui.closeDynamic(component)`** (called by window close buttons): writes the page's `default` path and params back as the current path and params. Blank if there is no default.
- The write helper `_write` merges the changes into the page's entry and assigns a new dict to `session.custom.efcDw`.

## Tag members used

None. The region reads and writes no tags. The windows it shows read their own tags, and the template that opens a window reads the template's tag.

## Notes and open questions

1. **Screen placement is not in this library.** No view under `projects/EFC_Library` embeds `Docks/Region`, so the screen-side settings (`defaultDock`, `defaultParams`, the region's width and height) can only be checked in the screen project.
2. **Re-creating the region resets it.** `setDefaultDock` writes the current path back to the default on every start. If the Region view is recreated while a window is open (a page change that remounts it, for example), that window is replaced by the default. Confirm the intended behaviour with the screens.
3. **No default, no way back.** If `defaultDock` is empty, `closeDynamic` writes a blank path, so the region is empty after a close. Set `defaultDock` on every screen that has dynamic windows.
4. **Entries are never removed.** `session.custom.efcDw` grows by one entry per page instance and is not cleared when a page closes. This is small, but it is not cleaned up.
5. **Invalid view path.** If a template opens a window whose path does not exist, `Window` gets the path and nothing checks it. `openDynamic` only checks the window id against `WINDOWS`. Whether Perspective shows an error or a blank area is not visible in this repository.
6. **Window size.** `Window` does not use the default width or height, so the window's size is the region's size. The 400 x 860 default is applied only where the screen embeds this view without its own size. The screen project decides that.
7. **The `dockId` and `tType` lookup is in `code.py`, not here.** `WINDOWS` and `BY_TYPE` map ids and types to views. A new window needs an entry in both, and in `build_docks.py` (`VIEWS`), or it cannot be opened from a template.
8. **`Templates/Dynamic Window/Station/Station` is not in the generator.** `WINDOWS` maps `dw_Station` to `Templates/Dynamic Window/Station/Station`, and `Templates/Station/_Demo` names `Templates/Dynamic Window/Station/Station` as a view path. `build_docks.py` does not generate `Templates/Dynamic Window/Station/Station`, and its `build()` removes the whole `EFC_Docks` folder before writing. Check where `Templates/Dynamic Window/Station/Station` is kept before the next build.
