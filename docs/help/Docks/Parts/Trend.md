# Docks/Parts/Trend

Source: `projects/EFC_Library/com.inductiveautomation.perspective/views/Docks/Parts/Trend/view.json`
Generated by `generator/docks/build_docks.py` (`trend_part()`). Change the generator, not `view.json`.
Embedded in: the dock windows `Docks/ValveDiscrete`, `Docks/ValveAnalog`, `Docks/Rotating`, `Docks/VFD`, `Docks/Heater`, `Docks/HeatTransfer`, `Docks/ProcessValue` and `Docks/Loop`. Each host has an embedded component named `Trend`. See [ValveDiscrete](../ValveDiscrete.md) for the host pattern.

## Overview

A history graph of up to three pens (tag members) of one device, with a title, range buttons and axis labels. It is embedded in a dock window and can be expanded in place.

- **Default size:** 384 x 170 (`props.defaultSize`).
- **Height in the host:** the generated hosts bind the embedded view's `position.basis` to the `expanded` param: `70.370vh` (760 px) when expanded, `15.741vh` (170 px) when not. Width comes from the host window; the graph is never made wider than that (generator decision 26, per its docstring).
- **Embedded with:** `params: {tagPath: "", pens: [...], expanded: false}`. The host binds `tagPath` to `{view.params.tagPath}`.
- **Opening:** not opened by itself. The Expand button inside the view toggles `expanded`.
- **Generated view:** yes, `trend_part()` in `generator/docks/build_docks.py`.

## How it operates

**Header.** A title, `History (<range>)`, where the range is 30 min, 5 min, 1 h, 8 h or 24 h. Five range buttons (`R24h`, `R8h`, `R1h`, `R30m`, `R5m`) are shown only while expanded. The selected range is shown in `Button/TabActive`. The Expand button (`⤢`) toggles `params.expanded`.

**Graph.** An SVG with a fixed `viewBox` of `0 0 360 100` and `preserveAspectRatio: none`, so it stretches to the host width and height. It has three `path` elements, drawn in this order:

| Element | Stroke colour (width 1.5) | Pen |
|---|---|---|
| `elements[0]` | `#1F1F1F` | first pen in `pens` |
| `elements[1]` | `#1F4E99` | second pen |
| `elements[2]` | `#7F7F7F` | third pen |

Each path's data comes from `custom.hist.d[i]`. An empty string draws nothing, so a host with two pens shows two traces, and the third path is empty (its `try()` guard catches the missing index).

**Axis.** Three labels under the graph: `Lo` (lowest plotted value, with padding), `Span` (`-<range>  ..  now`), and `Hi` (highest plotted value). Values are formatted with `%.4g`. There is no pen legend and no units.

**Data.** The `hist` binding is re-evaluated when the range changes and about every 10 seconds (the `now(10000)` term). The transform calls `efc.ui.trend`, which queries tag history for `tagPath/<pen>` over the last `range` minutes (see the library function below). All pens share one vertical scale, so BOOL pens (for example `Out_Open`, `Sts_Opened`) are plotted on the same scale as analog values. Each pen is 0 or 1 in that case.

**Errors.** A failed history query, or no history, gives empty paths and blank axis labels. Nothing is shown to the user.

## Scripts reference

Total: **6 event scripts** (`onActionPerformed`) and **1 transform script**. No `customMethods`, `messageHandlers`, property-change scripts or `view.scripts`.

1. **`root/Header/Ranges/R24h`**: `onActionPerformed`. `self.view.custom.range = 1440`. Selects a 24-hour window.
2. **`root/Header/Ranges/R8h`**: `onActionPerformed`. `self.view.custom.range = 480`. Selects 8 hours.
3. **`root/Header/Ranges/R1h`**: `onActionPerformed`. `self.view.custom.range = 60`. Selects 1 hour.
4. **`root/Header/Ranges/R30m`**: `onActionPerformed`. `self.view.custom.range = 30`. Selects 30 minutes (the default).
5. **`root/Header/Ranges/R5m`**: `onActionPerformed`. `self.view.custom.range = 5`. Selects 5 minutes.
   Each of these changes the range, which re-runs the `hist` binding.
6. **`root/Header/Expand`**: `onActionPerformed`.
   ```python
   self.view.params.expanded = not self.view.params.expanded
   ```
   Toggles the inout `expanded` param. The host reads the new value through its `position.basis` binding, so the graph grows or shrinks, and the range buttons appear or disappear.
7. **`view custom.hist`**: transform on the binding.
   ```python
   return efc.ui.trend(self.view.params.tagPath, list(self.view.params.pens or []), self.view.custom.range, 360, 100)
   ```
   Builds the SVG paths and axis labels for the current pens and range.

### Library functions called by this view (`efc.ui`, `projects/EFC_Library/ignition/script-python/efc/ui/code.py`)

- **`efc.ui.trend(base, pens, minutes, w, h)`**: returns `{d, lo, hi}`. With no `base` or no `pens`, it returns empty values. Otherwise it calls `system.tag.queryTagHistory` for the paths `base/<pen>` over the last `minutes`, with `returnSize` 200, `aggregationMode` `Average`, `returnFormat` `Wide` and `ignoreBadQuality` True. A query exception returns empty values. Each row becomes a point `x = w * i / n`, `y = h - (value - lo) / (hi - lo) * h`, where `lo` and `hi` are the min and max of all plotted values, padded by 10 % (at least 0.5). The path starts with `M` and joins the points with `L`. It writes no tags and performs no role check.

## Notes and open questions

1. **No pen legend or units.** The three pens are drawn in fixed colours (dark, blue, grey), but nothing in the view says which is which. The order follows the host's `pens` list. The units are not shown anywhere.
2. **Shared scale for BOOL and analog pens.** On the valve hosts (`Out_Open` and `Sts_Opened`) the data is 0 or 1, so the padded axis runs from -0.5 to 1.5. On the loop host, `Val_PV` (EU), `Val_SP` (EU) and `Out_CV` (%) share one scale, so their units do not match and the scale is set by whichever has the widest range.
3. **A non-numeric pen would fail the transform.** `float()` is applied to every value outside the `try` around the query. A STRING pen would raise an error in the transform, so the graph would not update. No current host passes a string pen.
4. **Query errors are silent.** `efc.ui.trend` returns empty data when the query raises. Missing history therefore looks like an empty graph, not an error.
5. **Refresh every 10 seconds.** The `now(10000)` term re-runs the query about every 10 seconds for each open trend, plus on each range change. That is a fixed load on the history provider, independent of the range.
6. **Resolution.** Up to 200 points are requested for every range, so the 24-hour view has about one point every 7 minutes. Spikes shorter than that are averaged out.
7. **The `expanded` param drives the host height only in the generated hosts.** Any other host that embeds this view must bind `position.basis` itself, or the expand button will change the param without changing the size.
