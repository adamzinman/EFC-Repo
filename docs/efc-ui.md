# efc.ui reference

`efc.ui` is the project script module behind the EFC dynamic windows. It opens a device's window in the page's right dock, sends operator commands to PLC `Cmd_` members, checks the user's access level before each command, writes the bypass and unbypass requests, and builds the trend graph. Everything in this page is taken from the code as it stands in `generator/docks/efc_ui.py`. Where the code and a steward decision disagree, the difference is listed in section 9.

## 1. Overview

| Item | Value |
|---|---|
| Module | `efc.ui` (Ignition project script package `efc`, module `ui`) |
| Shipped file | `projects/EFC_Library/ignition/script-python/efc/ui/code.py` |
| Source | `generator/docks/efc_ui.py` |
| Generator | `generator/docks/build_docks.py`, function `build()`, which copies `efc_ui.py` byte for byte to `code.py` and writes `resource.json` with `"scope": "A"` |
| Build entry | `build.py` runs `docks/build_docks.py` (in the `GENERATED_PARTS` list that includes `EFC_Docks`) |
| Language | Jython 2.7 (the module uses `basestring`, so it does not run under CPython 3) |
| Ignition version | 8.1.19 or later for `system.perspective.alterDock` and `openDock` (decision 31). The EFC library as a whole requires 8.1.22 (see [library-reference.md](library-reference.md)). The file header says "8.3 compatible"; that is not tested here. |

Edit `efc_ui.py`, never `code.py`. A build overwrites `code.py`.

**Who uses it.** Three kinds of caller:

- **Template and window event scripts** (generated): symbol `onClick` and `onDoubleClick`, the window ✕ button, command, mode, preset and ACK buttons, the bypass and unbypass buttons, and the trend part's history binding.
- **Hand-built views** in `projects/` and `imported/`: the Station window (source `imported/EFC_StationFaceplates/.../Station_Sidebar`), the Station tile, `Station_Fill` and the I/O slot tile.
- **Other generators**: `generator/build_pid.py`, `generator/build_pv.py`, `generator/analog_indicators/gen_analog_indicators.py` and `generator/pid_loops/generate_loops.py` write `efc.ui` calls into template events.

Two behaviours to keep in mind:

- Opening a window is not access-checked. Every user can open every window, and each window shows its controls according to the user's level.
- Access checks in this module are an operator aid. Enforcement is Perspective security and the PLC (see section 6).

## 4. Function reference

Functions appear in file order. "Required level" is the minimum `userLevel` the function enforces, not the level of its callers. A function with no level has no access check of its own.

### `_log()`

- **Signature:** `_log()`
- **Does:** returns `system.util.getLogger('efc.ui')`.
- **Side effects:** none.
- **Errors:** none caught.
- **Called by:** every function that logs.

### `_p(params, name, default=None)`

- **Does:** reads `name` from a Perspective params object, a dict, or a session property. Tries attribute access first, then item access. Returns `default` if both fail or the value is `None`.
- **Errors:** both lookups are inside `try`, so a missing key returns `default` and nothing is logged.
- **Called by:** most functions in this module.

### `_names(node, out)`

- **Signature:** `_names(node, out)`, where `out` is a list that is appended to and returned.
- **Does:** collects every name in a security-level tree. Cases, in order:
  1. `None`: returns `out` unchanged.
  2. A string: splits on `/` and appends the parts. `'Authenticated/Roles/Operator'` gives three names.
  3. A node with a `name`: appends `str(name)`, then recurses into `children`.
  4. Anything else: iterates it and recurses on each item. A dict without `name` is iterated over its keys.
- **Errors:** a non-iterable node is ignored (`TypeError` caught).
- **Called by:** `level` only.

### `_rank(name)`

- **Does:** maps one name to a level. Strips and lower-cases it, looks it up in `ROLE_ALIASES` (with the value lower-cased), then matches it case-insensitively against `ROLES`. Returns the index (0 to 5), or 0 if nothing matches.
- **Called by:** `level` only.

### `level(levels)`

- **Signature:** `level(levels)`
- **Does:** returns the highest `_rank` of every name found by `_names(levels)`. `levels` can be a security-level tree or a plain list of role names. Returns an int from 0 to 5.
- **Side effects:** none.
- **Required level:** none.
- **Called by:**
  - the `custom.level` property binding in every generated window (`build_docks.py`, class `View`), which passes `session.props.auth.securityLevels`;
  - the lock logic in `build_pid.py` (`access_lock`), which uses the same binding on each device template;
  - `Templates/Dynamic Window/Station/Station` (its `custom.level` binding);
  - `imported/EFC_StationFaceplates/.../Station_Sidebar` (its `custom.level` binding).
- **Note:** the view binding uses only `securityLevels`. Enforcement (`userLevel`) also uses `user.roles` (section 6).

### `userLevel(component)`

- **Signature:** `userLevel(component)`
- **Does:** returns `max(level(auth.securityLevels), level(auth.user.roles))`, where `auth = component.session.props.auth`.
- **Errors:** the line `auth = component.session.props.auth` is a plain attribute read, not guarded. A session without `props.auth` raises. The two level reads are guarded by `_p`.
- **Called by:** `cmd`, `denied`, `bypass`, `unbypass`, `ackAll`, `dblCmd`, and the Station window and `Station_Fill` scripts (`efc.ui.userLevel(self) < 1` before `denied`).

### `denied(component, minLevel, action='')`

- **Signature:** `denied(component, minLevel, action='')`
- **Does:**
  1. `have = userLevel(component)`; `need = ROLES[clamp(minLevel)]`.
  2. `user = auth.user.userName`, or `''` if missing.
  3. Logs a warning: `Refused <action> for <user or 'not signed in'> (<have role>): needs <need>`. This happens on every call, including repeats the dedupe suppresses.
  4. Dedupe. Reads `session.custom.efcDenied` (`{'action', 't'}`). If the last refusal had the same `action` and happened less than 1500 ms ago (`system.date.toMillis(system.date.now())`), it returns without opening the popup. Otherwise it stores `{'action': action, 't': now}`. If this check throws, it logs `denied: dedupe check failed: <error>` and continues.
  5. `system.perspective.openPopup('efcAccessDenied', 'Templates/Dynamic Window/Parts/AccessDenied', params={'action', 'need', 'have', 'user'}, title='Invalid access level', modal=True, showCloseIcon=True, overlayDismiss=True)`. If it throws, logs `denied: could not open <view>: <error>`.
- **Parameters:** `minLevel` is clamped to 0 to 5. `action` is the text shown in the popup and the log, such as `XV101 Cmd_Open`.
- **Returns:** `None`.
- **Side effects:** one warning log line; `session.custom.efcDenied` is set (not reset when the popup fails); one popup, unless suppressed.
- **Required level:** none. This is the refusal path.
- **Called by:**
  - `cmd`, when the level is too low and `notify` is true;
  - `unbypass` (`'Unbypass <idx>'`);
  - `ackAll` (`'<tag> ACK'`);
  - `dblCmd` (`'<tag> double-tap command'`);
  - the Station window and `Station_Fill` scripts for Tare, Zero and Reset (minimum 1).

### `_target(component, member)`

- **Does:** builds a short label for logs and popups. Takes the last segment of `view.params.tagPath` after the last `/` and `]`, then appends `member`. Example: `[default]Plant/XV101` with `Cmd_Open` gives `XV101 Cmd_Open`. An empty path gives just the member.
- **Side effects:** none.
- **Called by:** `cmd` (denial action), `ackAll`, `dblCmd`.

### `_writeTags(paths, values, what)`

- **Does:** calls `system.tag.writeBlocking(paths, values)`. For each result whose quality is not good, logs `<what>: write <path> failed: <quality>`. Returns `True` only if every write was good. An empty list returns `True`.
- **Errors:** an exception from `writeBlocking` itself is not caught; it reaches the calling button script.
- **Called by:** `cmd` (`what='cmd'`), `bypass` (`'bypass'`), `unbypass` (`'unbypass'`), `ackAll` (`'ackAll'`), `dblCmd` (`'dblCmd'`).

### `_state(component)`

- **Does:** returns `(s, pid, st)`:
  - `s = component.session.custom`, with `s.efcDw` created as `{}` if missing;
  - `pid = '<pageId>|<path>'` from `component.page.props`;
  - `st` is a copy of `s.efcDw[pid]` (or `{}`).
- **Why the key has the path:** `pageId` is kept across `navigate()`, so the path keeps one screen's default from applying to the next.
- **Side effects:** may create `session.custom.efcDw`. Writes nothing else.
- **Called by:** `_write`, `closeDynamic`.

### `_write(component, **changes)`

- **Does:** merges `changes` into this screen's state and writes `session.custom.efcDw` back as a new dict (so Ignition sees the change).
- **Side effects:** `session.custom.efcDw[pid]` is replaced.
- **Called by:** `setDefaultDock` only.

### `showDock(path, params=None)`

- **Does:** copies `params`, then calls `system.perspective.alterDock(DOCK_ID, {'view': path, 'viewParams': params})`, then `system.perspective.openDock(DOCK_ID, params=params)`.
- **Errors:** not caught. If the API is missing (Ignition below 8.1.19), or the view path is wrong, the exception reaches the calling script.
- **Note:** the key names `view` and `viewParams` are what the code passes. Confirm them against the `alterDock` documentation for your Ignition version if the dock does not change.
- **Called by:** `openWindow`, `setDefaultDock`, `closeDynamic`. No shipped view calls it directly.

### `openWindow(dw, tagPath, model=None)`

- **Does:** if `dw` is not in `WINDOWS`, logs `openWindow: unknown dynamic window <dw>` and returns. Otherwise builds `{'tagPath': tagPath or ''}`, adds `model` if it is truthy, and calls `showDock(WINDOWS[dw], params)`.
- **Returns:** `None`.
- **Called by:** `openDynamic`. Scripts can call it directly (documented in [library-reference.md](library-reference.md)); no shipped view does.

### `openDynamic(component)`

- **Does:**
  1. `p = component.view.params`.
  2. `dw = p.dockId`, or if empty `BY_TYPE.get(p.tType, '')`. A non-empty `dockId` that is not in `WINDOWS` does not fall back to `BY_TYPE`.
  3. If `dw` is not in `WINDOWS`, logs `openDynamic: no window for tType=<tType> dockId=<dockId>` and returns.
  4. `tp = dwTagPath`, else `tagPath`, else `cardPath`, else `''`.
  5. `openWindow(dw, tp, p.model)`.
- **Side effects:** via `openWindow`.
- **Required level:** none. Opening is not access-checked.
- **Called by:**
  - every generated device symbol's `onClick` (`build_pid.py` `symbol()`, two symbols in `build_pv.py`, `gen_analog_indicators.py`, `generate_loops.py`);
  - `imported/EFC_IOFaceplates` `IO/Parts/SlotTile` (passes `model`; its `cardPath` is the `tagPath` fallback);
  - `imported/EFC_StationFaceplates` `Templates/Station/Station_Tile` (`tType` `T_Station`).

### `setDefaultDock(component, viewPath, params=None)`

- **Does:** if `viewPath` is truthy, copies `params`, stores `{'default': {'path': viewPath, 'params': params}}` for this screen (`_write`), and calls `showDock(viewPath, params)`. An empty `viewPath` does nothing; it does not clear an earlier default.
- **Intended caller:** a screen's root `onStartup`.
- **Called by:** no shipped view (section 2, step 5).

### `closeDynamic(component)`

- **Does:** reads this screen's default. If it has a `path`, calls `showDock(path, params)`. Otherwise calls `system.perspective.closeDock(DOCK_ID)`.
- **Called by:** the ✕ button in the header of every generated window (`build_docks.py` `header()`), and the Station window's ✕ button.

### `_audit(component, action, target, value='')`

- **Does:**
  1. `user = component.session.props.auth.user.userName`. Not guarded.
  2. `system.util.audit(action=action, actionTarget=target, actionValue=str(value), actor=user)`, inside `try`. Any exception is swallowed without a warning.
  3. Logs `AUDIT <action> <target> <value> by <user>` at info, whether or not step 2 worked.
- **Side effects:** an audit record (if the audit profile accepts it) and an info line.
- **Called by:** `cmd` (when `audit=True`, action `'EFC write'`), `bypass` (`'EFC bypass'`), `unbypass` (`'EFC unbypass'`).

### `cmd(component, member, value=True, minLevel=OPERATOR, audit=False, notify=True)`

- **Does:**
  1. If `userLevel(component) < minLevel`: if `notify`, calls `denied(component, minLevel, _target(component, member))`. Returns `False`. No write.
  2. `tp = view.params.tagPath + '/' + member`.
  3. `ok = _writeTags([tp], [value], 'cmd')`.
  4. If `audit`: `_audit(component, 'EFC write', tp, value)`. This runs whether or not the write succeeded.
  5. Returns `ok`.
- **Parameters:**
  - `member`: a member path relative to the view's tag, such as `Cmd_Open` or `Mode/Cmd_Auto`.
  - `value`: written as given (`True`, `False`, or a number).
  - `minLevel`: default `OPERATOR` (1).
  - `audit`: default `False`.
  - `notify`: `False` suppresses the refusal popup and its log line (used for jog release).
- **Returns:** `True` if the write was good. `False` if refused or if the write failed.
- **Side effects:** one tag write; on refusal, a warning and possibly the popup; on a failed write, a warning; on `audit`, one audit record.
- **Errors:** a `None` `tagPath` raises a `TypeError` from the concatenation. An empty `tagPath` writes to `/<member>`, which fails and is logged.
- **Required level:** `minLevel`, checked against `userLevel`.
- **Called by:**
  - device template Manual buttons (`build_pid.py`, `minLevel` 1);
  - the window `commands()` and `button()` helper: mode buttons (`build_docks.py` `mode_section`, minimum 1 for AUTO and MAN, 2 for MAINT and OOS with `audit=True`), command and preset buttons, FWD and REV, and the jog press and release;
  - `maint()`: RESET MAINT and SIMULATE, both minimum 2 with `audit=True`;
  - `intlk_list()`: RESET, minimum 2 with `audit=True`;
  - `entry(..., scale=TIME_SCALE)`: an Engineer (4) setpoint, `audit=True` (section 9);
  - the Loop mode buttons (`minLevel` 1);
  - the Station window and `Station_Fill` scripts: `Cmd_Select` (minimum 1, momentary) and the pending Tare, Zero and Reset commands (minimum 1, momentary).

### `bypass(component, intlkPath, idx, reason)`

- **Does:**
  1. `reason = (reason or '').strip()`.
  2. If `userLevel < SUPERVISOR` or `reason` is empty, returns `False`. Silent: no write, no log, no popup.
  3. `_writeTags(['<intlkPath>/Cmd_Bypass/<idx>'], [True], 'bypass')`.
  4. `_audit(component, 'EFC bypass', '<intlkPath>/<idx>', reason)`.
  5. Returns `True`.
- **Returns:** `True` after the write attempt, even if the write failed. The caller closes its popup on `True`.
- **Side effects:** one tag write and one audit record (written after the write attempt, whatever its result).
- **Required level:** Supervisor (3), plus a non-empty reason.
- **Called by:** the BypassConfirm view's BYPASS button (`build_docks.py` `bypass_confirm()`). It is called with the BypassConfirm view's `params.tagPath` (the IntlkList path, ending in `/Intlk`), `params.idx` and `custom.reason`.
- **Not checked here:** `Inp_BypassPerm` (named in decision 10) and the duration (`Cfg_BypassMax` is only mentioned in the popup text).

### `unbypass(component, intlkPath, idx)`

- **Does:** if `userLevel < SUPERVISOR`, calls `denied(component, SUPERVISOR, 'Unbypass <idx>')` and returns. Otherwise writes `<intlkPath>/Cmd_Unbypass/<idx>` = `True` (`'unbypass'`) and calls `_audit(component, 'EFC unbypass', '<intlkPath>/<idx>')` with no value.
- **Returns:** `None`.
- **Side effects:** one write and one audit record. The audit record is written even if the write failed.
- **Required level:** Supervisor (3).
- **Called by:** the IntlkList UNBYP button (`build_docks.py` `intlk_list()`). The button is shown only at Supervisor and above, so the denial path is a fallback.

### `ackAll(component, alarms)`

- **Signature:** `ackAll(component, alarms)`, where `alarms` is a list of member names such as `Alm_FailOpen`.
- **Does:**
  1. If `userLevel < OPERATOR`: `denied(component, OPERATOR, _target(component, 'ACK'))`, then returns.
  2. `base = view.params.tagPath`.
  3. `readBlocking` of `<base>/<alarm>/Sts_Unack` for each alarm.
  4. Builds `<base>/<alarm>/Cmd_Ack` for each alarm whose `Sts_Unack` value is truthy.
  5. If any, `_writeTags(paths, [True, ...], 'ackAll')`.
- **Returns:** `None`.
- **Side effects:** writes `Cmd_Ack` = `True` on each unacknowledged alarm. No log line, no audit record.
- **Notes:** `Sts_Active` is not read. A read with a `None` value is skipped. `readBlocking` is not wrapped in `try`.
- **Required level:** Operator (1).
- **Called by:** the ACK button in the `alarms()` section of each window (`build_docks.py`). The button is `need=OP`.

### `_num(v)`

- **Does:** returns `float(v)`, or `None` if `v` is `None` or not numeric (`TypeError` and `ValueError` are caught).
- **Called by:** `trend`.

### `trend(base, pens, minutes, w, h)`

- **Signature:** `trend(base, pens, minutes, w, h)`. `base` is the tag path, `pens` a list of member names, `minutes` the range, `w` and `h` the SVG size.
- **Does:**
  1. Returns `{'d': ['', ...], 'lo': '', 'hi': ''}` if `base` or `pens` is empty.
  2. `system.tag.queryTagHistory(paths=[base/pen...], rangeMinutes=int(minutes), returnSize=200, aggregationMode='Average', returnFormat='Wide', ignoreBadQuality=True)`. On exception, logs `trend: queryTagHistory failed for <base>: <error>` and returns the empty result.
  3. Builds one row per timestamp: `[_num(value in column c+1) for each pen]`. Column 0 is the timestamp.
  4. If there are fewer than 2 rows or no numeric values, returns the empty result.
  5. `lo`, `hi` = min and max of all values. `pad = max((hi - lo) * 0.1, 0.5)`, applied to both ends.
  6. For each pen, points `x = w * i / (rows - 1)` and `y = h - (v - lo) / (hi - lo) * h` for every non-`None` value. `d = 'M' + ' L'.join(points)` if there are at least two points, else `''`.
  7. `lo` and `hi` are returned as strings with `'%.4g'`, after padding.
- **Returns:** `{'d': [one path string per pen], 'lo': str, 'hi': str}`.
- **Side effects:** none except the warning on exception.
- **Required level:** none.
- **Notes:** the requested sample count is 200. The Trend view draws at most three paths (section 9).
- **Called by:** the `custom.hist` binding in the Trend part (`build_docks.py` `trend_part()`). The binding passes `view.params.tagPath`, `view.params.pens`, `view.custom.range` and 360 x 100.

### `dblCmd(component)`

- **Signature:** `dblCmd(component)`. Called from the device symbol's `onDoubleClick`.
- **Does:**
  1. `p = view.params`. Returns silently if `p.useButton` is truthy, `p.dblCmd` is falsy, or `p.tType` is not in `DBL_CMD`.
  2. If `userLevel < OPERATOR`: `denied(component, OPERATOR, '<tag> double-tap command')`, then returns.
  3. Reads `<base>/<state>`, every `READY_TRUE` member, and every `READY_FALSE` member, in one `readBlocking`.
  4. `isOn` = the state value. `ready` = the `READY_TRUE` values. `blocked` = the `READY_FALSE` values.
  5. If `not all(ready)` or `any(blocked)`, returns silently. A `None` value counts as not ready and as not blocked. Quality codes are not checked.
  6. Writes `<base>/<cmdOn>` if `isOn`, else `<base>/<cmdOff>`, `= True` (`'dblCmd'`).
- **Returns:** `None`.
- **Side effects:** one write when all checks pass. No log line and no audit record when the readiness check fails.
- **Required level:** Operator (1).
- **Called by:** the `onDoubleClick` of generated `T_DValve` and `T_Motor` symbols (`build_pid.py`). Both are generated with `useButton = false` and `dblCmd = true`.
- **Notes:**
  - For `T_DValve`, any state other than `Sts_Opened` (including moving) sends `Cmd_Open`.
  - `build_pid.py` attaches the `onDoubleClick` handler only to `T_DValve` and `T_Motor`, so `T_VFD` and `T_Heater` never call `dblCmd`. If it is called for another type, it returns silently.

## 5. Flows

### 5.1 Template click opens the dynamic window in `dw_Right`

1. The operator clicks a device symbol. Its `onClick` runs `efc.ui.openDynamic(self)`.
2. `openDynamic` takes `dockId` from the template params. If it is empty, it uses `BY_TYPE[tType]`.
3. If no window id is found, it logs `openDynamic: no window for ...` and stops.
4. The tag path is `dwTagPath`, else `tagPath`, else `cardPath`.
5. `openWindow` looks up the view path in `WINDOWS` and builds `{'tagPath': ..., 'model': ...}` (`model` only if set).
6. `showDock` calls `alterDock('dw_Right', {view, viewParams})`, then `openDock('dw_Right', params)`.
7. The window view reads `view.params.tagPath` and binds its members. Its `custom.level` comes from `session.props.auth.securityLevels`.

### 5.2 Window close button (✕)

1. The ✕ button runs `efc.ui.closeDynamic(self)`.
2. `_state` reads the default for this screen (key `<pageId>|<path>`).
3. If a default `path` is stored, `showDock(path, params)` puts it back.
4. Otherwise `system.perspective.closeDock('dw_Right')` closes the dock.

### 5.3 Default dock view per screen (optional)

1. The screen's root `onStartup` calls `efc.ui.setDefaultDock(self, viewPath, params)`. **No shipped screen does this** (section 2).
2. `setDefaultDock` stores `{'default': {'path', 'params'}}` under `session.custom.efcDw['<pageId>|<path>']`.
3. It calls `showDock(viewPath, params)`, so the default is shown on load.
4. A window's ✕ then returns to this default (flow 5.2).

### 5.4 Command press with access check

Example: the Manual button on a device symbol (`minLevel` 1), or a window command button with `need` set.

1. Before the press, the button is visible. If `custom.level` is below `need`, a lock icon and a "Requires <role> access" tooltip show. The button is still enabled, so a press can reach `efc.ui`.
2. The press runs `efc.ui.cmd(self, member, True, lv, audit=...)`.
3. `cmd` computes `userLevel` (the higher of securityLevels and user.roles).
4. **Refused** (`userLevel < minLevel`):
   1. `denied` logs `Refused <action> for <user> (<have>): needs <need>`.
   2. If the same action was refused less than 1500 ms ago, the popup is not opened.
   3. Otherwise the AccessDenied popup opens: "Invalid access level", with the action, the role needed, and who is signed in.
   4. `cmd` returns `False`. Nothing is written.
5. **Allowed**: `writeBlocking([<tagPath>/<member>], [value])`.
   1. **Write good**: `cmd` returns `True`. If `audit`, an `EFC write` audit record and `AUDIT` info line are written.
   2. **Write bad** (missing member, bad quality): `cmd` logs `cmd: write <path> failed: <quality>`, returns `False`. If `audit`, the audit record is still written.

### 5.5 Jog press and release (`Cmd_Jog`, `notify=False`)

1. `onMouseDown` and `onTouchStart`: `if self.props.enabled: efc.ui.cmd(self, 'Cmd_Jog', True, 2)`. The button is enabled only in MAINT mode with the other ready conditions met, or when locked (lock icon shown).
2. Refused press: the popup opens. One touch fires both events; the refusal dedupe stops a second popup for the same action within 1.5 s.
3. `onMouseUp`, `onMouseLeave`, `onTouchEnd`: `efc.ui.cmd(self, 'Cmd_Jog', False, 2, notify=False)`. The release writes `False` whenever the level passes. If the level fails, `cmd` returns `False` silently: no popup and no log (the log is inside the `notify` branch).
4. Jog is `Cmd_Jog`, which the window releases itself. Other `Cmd_` members are not released by `efc.ui` (section 9).

### 5.6 Double-tap command (touch mode)

1. The device symbol has `onClick` (opens the window) and `onDoubleClick` (`efc.ui.dblCmd(self)`). A double tap therefore runs both (the click side is standard DOM behaviour, inferred from the wiring, not observed).
2. `dblCmd` returns silently unless `useButton` is false, `dblCmd` is true, and `tType` is in `DBL_CMD`. These are set by `build_pid.py` for `T_DValve` and `T_Motor` only.
3. Below Operator: refused with the AccessDenied popup (`'<tag> double-tap command'`).
4. One `readBlocking` reads the state, `Mode/Sts_Man`, `Sts_Avail`, `Sts_Intlk`, `Sts_NotPerm`, `Sts_Local` and `Sts_Fault`.
5. Not in Manual, not available, interlocked, not permitted, local or faulted: return silently. No log, no popup.
6. Otherwise write the on or off command (`Cmd_Close` or `Cmd_Open` for `T_DValve`; `Cmd_Stop` or `Cmd_Start` for `T_Motor`) as `True`. No audit record.

### 5.7 ACK

1. The ACK button in a window's Alarms section runs `efc.ui.ackAll(self, [<alarm names>])` (`need` Operator).
2. Below Operator: refused with the popup (`'<tag> ACK'`).
3. Reads `<alarm>/Sts_Unack` for each name. Writes `<alarm>/Cmd_Ack` = `True` for each truthy value.
4. No log line, no audit record, nothing shown when no alarm is unacknowledged.

### 5.8 Bypass and unbypass

**Bypass:**

1. An IntlkList row shows BYPASS when `lvl(SUP)`, the condition is `Cfg_Bypassable`, and it is not already bypassed. Its inline script calls `system.perspective.openPopup('efcBypass', 'Templates/Dynamic Window/Parts/BypassConfirm', params={'tagPath', 'idx', 'desc'}, ...)`. This popup script is inline in the view, not `efc.ui`.
2. BypassConfirm shows the reason field (`custom.reason`). The Ok button is enabled when the level is Supervisor and the trimmed reason is not empty. The view enforces this, not `efc.ui`.
3. Ok runs `efc.ui.bypass(self, tagPath, idx, reason)`.
   - Level below Supervisor, or reason empty: returns `False`. The popup stays open with no message.
   - Otherwise: writes `<tagPath>/Cmd_Bypass/<idx>` = `True`, writes the audit record `EFC bypass` (target `<tagPath>/<idx>`, value = reason), and returns `True`.
4. On `True`, the popup closes with `closePopup('efcBypass')`. The write result is not checked (section 9).
5. Cancel only closes the popup.

**Unbypass:**

1. The UNBYP button (shown at Supervisor and above, when bypassed) runs `efc.ui.unbypass(self, tagPath, idx)`.
2. Below Supervisor: refused with the popup (`'Unbypass <idx>'`).
3. Otherwise writes `<tagPath>/Cmd_Unbypass/<idx>` = `True` and writes the audit record `EFC unbypass` (no value). The audit is written whether or not the write succeeded.

### 5.9 Trend history query

1. The Trend part's `custom.hist` binding is re-evaluated about every 10 s (the expression depends on `now(10000)`).
2. Its transform calls `efc.ui.trend(view.params.tagPath, view.params.pens, view.custom.range, 360, 100)`.
3. `custom.range` is in minutes. The range buttons set it to 5, 30, 60, 480 or 1440. The default is 30.
4. `trend` queries history with `rangeMinutes = range`, builds one SVG path per pen, and sets `lo` and `hi` for the axis labels.
5. The graph's three path elements are bound to `hist.d[0..2]`. Each path is one pen. The pen colours are `#1F1F1F`, `#1F4E99` and `#7F7F7F`.
6. The expand button flips the `expanded` in/out param. The window then grows the Trend view to 760 px high. The SVG keeps its 360 x 100 viewBox and stretches (`preserveAspectRatio="none"`).

## 6. Access levels

### 6.1 Where the level comes from

- The source is `session.props.auth.securityLevels`. `_names` walks it and collects every name. It accepts three shapes:
  1. **Nested nodes** with `name` and `children` (the Perspective security-level tree).
  2. **Path strings**, such as `Authenticated/Roles/Operator`, which are split on `/`.
  3. **Plain lists** of role names.
- Every name is matched by `_rank`: strip, lower-case, look up `ROLE_ALIASES`, then match `ROLES` case-insensitively. A name that matches nothing counts as 0.
- The level is the highest rank found anywhere in the tree. Structural names such as `Authenticated` and `Roles` rank 0 and do no harm.

### 6.2 Two levels: view and enforcement

| Use | Source | Where |
|---|---|---|
| Lock icon, tooltip, visibility of sections and controls (`custom.level`) | `securityLevels` only | Generated windows, Station window, device templates |
| Enforcement in `cmd`, `denied`, `bypass`, `unbypass`, `ackAll`, `dblCmd` (`userLevel`) | `max(securityLevels, user.roles)` | `efc.ui` functions |

So a user whose role is only in `session.props.auth.user.roles` can press a locked button and have it work, while the button still shows a lock. Section 9 lists this.

### 6.3 Roles

| Level | Role | Typical use in the windows |
|---|---|---|
| 0 | Guest | No role matched. Every command button shows a lock. No Operator-level control works. |
| 1 | Operator | AUTO and MAN, OPEN and CLOSE, START and STOP, setpoints, presets, FWD and REV, ACK, double-tap, Manual button |
| 2 | Maintenance | MAINT and OOS mode, JOG, RESET MAINT, SIMULATE, the Maintenance section, Maintenance-level simulation |
| 3 | Supervisor | Bypass and unbypass (BYPASS and UNBYP are hidden below this level) |
| 4 | Engineer | Configuration and tuning edits, alarm limits. Only time-valued entries (scaled) are audit-logged. |
| 5 | Admin | Ranks above Engineer. No window control uses it as a minimum. |

Interlock RESET in IntlkList is `need=MAINT` with `minLevel` 2 (Maintenance), not Supervisor.

### 6.4 Locked, greyed or hidden

Three ways a control is restricted in the windows (decisions 27 and 33):

| Mode | Used for | What the user sees |
|---|---|---|
| **Locked** (`button(..., need=...)`) | Command buttons: mode, commands, presets, FWD and REV, ACK, interlock RESET, JOG, the Manual button | Visible, lock icon, tooltip "Requires <role> access". Pressing it is refused and shows the AccessDenied popup. |
| **Greyed** (`entry(..., grey=True)`) | Setpoint and position entries (Operator): Loop SP and CV, valve manual position, VFD speed, heater power | Visible but disabled below the level. |
| **Hidden** (`lvl(...)` in `position.display`) | Maintenance section, bypass and unbypass (Supervisor), configuration and tuning values (Engineer), alarm limits (Engineer) | Not shown below the level. |

### 6.5 What is enforced where

- `cmd` and the other functions in section 4 re-check the level before each write they make. For those writes they are the only check in this module.
- Bidirectional tag bindings (`entry` without `scale`, and `check`) write straight to the tag without calling `efc.ui`. For these, the only restriction is the client-side `props.enabled` or `position.display`. This is section 9, item 1.
- This is an HMI aid. Access must be enforced by Perspective security (page and view roles) and by the PLC (permissives, interlocks, and the commands the PLC accepts).

## 7. Logging and audit

### 7.1 Logger

All messages go to the logger `efc.ui`, obtained with `system.util.getLogger('efc.ui')`. The code sets no levels. Whether warnings and the `AUDIT` info line reach the gateway log depends on the gateway logging configuration for `efc.ui`.

### 7.2 Log messages

| Level | Message pattern | Written by | When |
|---|---|---|---|
| warn | `Refused <action> for <user or 'not signed in'> (<have role>): needs <need role>` | `denied` | Every refused command, including presses whose popup the 1.5 s dedupe suppressed. Not written when `cmd` is called with `notify=False`. |
| warn | `denied: dedupe check failed: <error>` | `denied` | Reading or writing `session.custom.efcDenied` fails. The popup still opens. |
| warn | `denied: could not open Templates/Dynamic Window/Parts/AccessDenied: <error>` | `denied` | `openPopup` raised. |
| warn | `<what>: write <tag path> failed: <quality>` | `_writeTags` with `what` = `cmd`, `bypass`, `unbypass`, `ackAll` or `dblCmd` | A write returned a bad quality (for example, a missing member). |
| warn | `openWindow: unknown dynamic window <dw>` | `openWindow` | A script calls `openWindow` with an id not in `WINDOWS`. |
| warn | `openDynamic: no window for tType=<tType> dockId=<dockId>` | `openDynamic` | A symbol's `tType` and `dockId` give no window. |
| warn | `trend: queryTagHistory failed for <base>: <error>` | `trend` | The history query raised. The graph is empty. |
| info | `AUDIT <action> <target> <value> by <user>` | `_audit` | Every audited action (section 7.3). Written after the write attempt, even if the write failed. |

Not logged: ACK, the double-tap readiness refusal, the bypass refusal (no level or no reason), the jog release refusal, and a trend query with no data.

### 7.3 Audit records

`_audit` calls `system.util.audit(action=..., actionTarget=..., actionValue=..., actor=...)`. If that call raises, the exception is swallowed without a warning. The info line is the fallback record.

| Action | Target | Value | Written by |
|---|---|---|---|
| `EFC write` | full tag path of the member | the value written | `cmd(..., audit=True)`: MAINT and OOS mode buttons, RESET MAINT, SIMULATE, IntlkList RESET, and Engineer scaled entries (time values) |
| `EFC bypass` | `<intlkPath>/<idx>` | the reason text | `bypass` |
| `EFC unbypass` | `<intlkPath>/<idx>` | empty | `unbypass` |

Notes:

- `EFC write` is written whether or not the write succeeded (`cmd` writes the audit after `_writeTags`, regardless of its result).
- Engineer scaled entries log only the new value. Decision 14 asks for old to new.
- Ordinary Engineer configuration values (no scale) are not audited (section 9).

## 8. Troubleshooting

| Symptom | Likely cause | Check or fix |
|---|---|---|
| A command button shows a lock although the user should have access | `securityLevels` does not carry the role name. The lock uses `securityLevels` only. | Read `session.props.auth.securityLevels` in a session script (or the Perspective session properties). Look for the role name. If the site uses another name, add its lower-case form to `ROLE_ALIASES`, then rebuild. |
| A user whose role is only in `user.roles` sees a lock, but the press works | The lock uses `securityLevels` only, enforcement also uses `user.roles` (section 6.2) | Put the role in `securityLevels` so the lock and the enforcement agree. |
| Log says `Refused ... (Guest)` for a user who should have a role | The name is not matched (case is ignored, spelling and spacing are not) | Read the security levels as above. The name must match a `ROLES` name, or an alias key (lower case). `'Operators'` matches through the alias; `'Operator Group'` does not. |
| Pressing a command does nothing (no popup, no log line) | The button is disabled (`props.enabled` false), so the press never reaches `efc.ui`. A refused press always logs. | Check the template's ready conditions (mode, `Sts_Avail`, `Sts_NotPerm`, `Sts_Intlk`, `Sts_Local`, `Sts_Fault` as used by that button). |
| Symbol click does nothing | `dockId` or `tType` gives no window | Gateway log: `openDynamic: no window for tType=... dockId=...`. Fix the template param. |
| Window opens, dock is blank, or the window is missing | View path wrong, or `alterDock` failed (Ignition below 8.1.19, or the view was renamed) | The exception from `alterDock` or `openDock` is not caught in `showDock`. Check the script error in the gateway or Designer log. Check the path against `WINDOWS`. |
| Window opens, but every value is empty or the commands fail | `view.params.tagPath` is empty (window opened without a tag) | Check the template's `tagPath`, and `dwTagPath` if set. Failed writes to `/Cmd_*` log `write /... failed`. |
| Popup does not appear on refusal | (a) The same action was refused less than 1.5 s ago (dedupe). (b) The view `Templates/Dynamic Window/Parts/AccessDenied` is missing. (c) The popup id `efcAccessDenied` is in use. | (a) Wait 1.5 s and press again, and read the `Refused` log line. (b) Confirm the view exists. (c) Gateway log: `denied: could not open`. |
| Command written but not acted on, with bad quality | Missing member (the type has no `Cmd_...`), read-only tag, bad quality (PLC or driver down) | Gateway log `efc.ui`: `cmd: write <path> failed: <quality>`. Check the member exists on the UDT and the tag quality. |
| Double-tap does nothing | (a) `useButton` is true (touch mode is off). (b) `dblCmd` is false. (c) `tType` is not `T_DValve` or `T_Motor`. (d) Not in Manual or not available, or interlocked, not permitted, local or faulted. (e) Below Operator (popup). | Check the template params (`useButton` must be false, `dblCmd` true). Check `Mode/Sts_Man`, `Sts_Avail`, `Sts_Intlk`, `Sts_NotPerm`, `Sts_Local`, `Sts_Fault`. The readiness refusal is silent. |
| Bypass popup stays open | Reason is empty, or the user is below Supervisor | Enter a reason. `bypass` returns `False` silently. |
| Bypass returned OK but nothing changed in the PLC | `bypass` returns `True` after the write attempt, even if the write failed | Gateway log `bypass: write ... failed`. Check the member and the tag quality. |
| Trend graph is empty | No history for the members, fewer than two samples, or the query raised | Gateway log `trend: queryTagHistory failed`. Check the members are historized. |
| Audit entry missing | No audit profile, or `system.util.audit` raised | Check the `AUDIT` info line in the gateway log (needs info level for `efc.ui`). |

## 9. Known limitations

Each item was checked in the code. The decision reference is given where the code and a steward decision differ.

1. **Bidirectional entries and checkboxes bypass `efc.ui`.** `entry(...)` without `scale`, and `check(...)`, bind `props.value` or `props.selected` to the tag with `tag(..., bidi=True)`. They write without `cmd`, without a level re-check, without a log line and without an audit record. This covers Loop `Cmd_SP` and `Cmd_CV`, valve `Cmd_ManPos`, VFD `Cmd_Spd`, heater `Cmd_Pwr`, Process Value `Sim_En` and `Sim_PV`, and every Engineer configuration value that is not time-scaled and every Engineer checkbox. Decision 27 says writes go through `efc.ui.cmd`; this is not true for these controls. Decision 14 asks for audit-logged configuration edits with old to new values; plain configuration edits are not audited.
2. **Commands are one-shot and the PLC must clear them.** `cmd` writes `True` and nothing writes `False`. The exceptions are `Cmd_Jog` (released by the window on release) and the Station window's `Cmd_Select`, `Cmd_Tare`, `Cmd_Zero`, `Cmd_Reset` (released by a 1 s timer in the view script, not by `efc.ui`). If the PLC does not clear a `Cmd_` member, it stays `True`.
3. **`bypass` returns `True` even when the write failed.** BypassConfirm closes on `True`, so a failed write is only visible in the log. Decision 10 also asks for `Inp_BypassPerm` and duration presets. Neither is in `efc.ui` or `build_docks.py`. `Cfg_BypassMax` is named in the popup text only.
4. **Shelving is not implemented.** Decision 14 names Supervisor shelving and `build_docks.py` lists it in its docstring. No code in `generator/docks/` creates it.
5. **Two level sources.** Locks and visibility use `securityLevels` only. Enforcement uses `max(securityLevels, user.roles)`. A user whose level comes only from roles can press a locked button. Decision 33 names `securityLevels` as the source.
6. **No default dock is wired.** `setDefaultDock` has no caller in `projects/` or `imported/`, and no view has a `defaultDock` param. Decision 2 and the Station window documentation (`docs/station-faceplates.md`) refer to a screen-level `setDefaultDock`. Until a screen calls it, ✕ closes the dock. Decision 32 leaves close without a default open.
7. **ACK has no log line, no audit, and does not read `Sts_Active`.** It acknowledges every alarm whose `Sts_Unack` is truthy.
8. **`audit=True` writes the audit record even when the write fails** (`cmd`, `unbypass`). `bypass` does the same.
9. **`_audit` reads `auth.user.userName` without a guard.** If `props.auth.user` is missing, the exception reaches the caller after a write has already succeeded (for `cmd` and `bypass`).
10. **Three pens at most.** `trend` computes one path per pen, but the Trend view has three path elements (`pen0`, `pen1`, `pen2`). Extra pens are computed and not drawn. All current windows pass three or fewer.
11. **`dblCmd` infers the state from one member.** For `T_DValve`, anything other than `Sts_Opened` sends `Cmd_Open`, including while moving. It does not read quality codes; a `None` value counts as not ready.
12. **Double tap also runs the click.** The symbol has both `onClick` and `onDoubleClick`, so a double tap also calls `openDynamic`. This follows from the wiring; it was not observed in a running session.
13. **Not tested here.** The module has no unit tests in the repo. Behaviour noted as "Ignition API" is taken from the code; the 8.1.19 dock calls and `system.util.audit` keyword names were not checked against a running gateway.
14. **Refusal dedupe is per browser session and per action.** A second action within 1.5 s shows its own popup. A repeat of the same action within 1.5 s shows no popup, but still logs.
15. **Steward copy is stale.** `steward/proposals/efc_ui_code.py` is an earlier embedded-view design (decision 24) and must not be used as source. The generator is `generator/docks/efc_ui.py`.
