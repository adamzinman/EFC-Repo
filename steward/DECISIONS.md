| 24 | 2026-10-21 | **Superseded by 31 (2026-10-22).** Dynamic windows use the embedded-view strategy, not Perspective docks: the screen shell's right region is an Embedded View whose path and params are bound to a per-page session value set by `efc.ui.openDynamic` (dynamic-window id + tagPath); close returns it to the screen's `defaultDock` view. Sized in vh (37.04 vh at 1080p), expands to about 50 % for the expanded trend. Ids keep the `dw_` names. Matches the Controls Standard screen design appendix. |
| 25 | 2026-10-21 | Shell sizes follow the Controls Standard rev I screen design appendix (design 1920 x 1080; double at 3840 x 2160): header 1920 x 80, left menu 120 x 860, main process area 1400 x 860, dynamic window 400 x 860, alarm bar 1920 x 140. The dynamic window fills the full height between header and alarm bar: 400 x 860 at 1080p = 37.04 vh x 79.63 vh (800 x 1720 at 4K). Corrects earlier mockups (header 60, alarm bar 70, menu 60, window 940 tall). Under decision 31 the dynamic window is the right dock: dock width 37.04 vh (400 px at 1920 x 1080, 800 px at 3840 x 2160, set at runtime by `efc.ui.sizeDock`); the window content inside it stays sized in vh. |
| 26 | 2026-10-21 | Graph expand stays inside the dynamic window: the window keeps its 400 x 860 size; the expanded graph fills the window below the header (about 400 x 760), with the range buttons (5 m / 30 m / 1 h / 8 h / 24 h), pause / live and a collapse button; the other sections are hidden until collapsed. Replaces the "about 50 % of the screen" behaviour in decisions 16 and 24; the shell's right region never changes width. Expand state is local to the window view (custom property), not a session value. |
| 27 | 2026-10-21 | Window controls below the user's role level are hidden, not greyed (efc.ui.level from session roles; Guest 0 .. Admin 5). Writes go through efc.ui.cmd, which re-checks the level server-side; bypass needs Supervisor+ and a reason and is audit-logged. |
| 28 | 2026-10-21 | EFC_Styles classes only is enforced in the generators: common.extract_inline moves static inline styles into generated classes per view; identical styles share a class. Bound style props stay bindings. Imported views get the same through steward/tools/fix_station_styles.py. |
| 29 | 2026-10-21 | Safety-related signals (safety PLC / SIS, E-stops, safety interlocks) can never be bypassed or forced in software. The decision 19 HMI bypass applies only to process conditions engineering marked Cfg_Bypassable (set at design under MOC, never on safety conditions). |
| 30 | 2026-10-21 | The Controls Standard names the class library EFC_Styles everywhere (replaces "dp style classes"; dp stays the text unit). |
| 31 | 2026-10-22 | **Supersedes 24.** Dynamic windows use a built-in Perspective right dock in push mode, not an embedded-view region: every screen page has a right (East) docked view with Dock ID `efcDynamic`, View `Docks/Host`, Content `push`, Display `visible`, Size 400 px at 1920 x 1080 (800 px at 3840 x 2160; `efc.ui.sizeDock` sets the width to 37.04 % of the viewport height from `Docks/Host`, needs 8.1.19+, not yet verified in a gateway). The dock sits between the header (full-width top dock) and the alarm bar (full-width bottom dock), not resizable, handle hidden. The dock takes its own column on the right; the process area (primary view) shrinks, nothing is covered. `efc.ui.openDynamic` calls `system.perspective.openDock('efcDynamic', params={path, tagPath, model})`; `Docks/Host` embeds that window. The screen's default view (normally its trends) is the dock's `defaultPath` / `defaultParams` View Parameters in Page Configuration; `efc.ui.closeDynamic` reopens the dock with an empty path, so `Docks/Host` shows the default again, or closes the dock (`closeDock`) when the page has none. `session.custom.efcDw`, `Docks/Region` and `efc.ui.setDefaultDock` are removed; template scripts and window ids (`dw_*`) are unchanged. The within-window graph expand (decision 26, about 400 x 760, width unchanged) stays. Screen setup: docs/dock-setup.md. Controls Standard change queued (DOC-QUEUE row 4). |
