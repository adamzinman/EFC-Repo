| 31 | 2026-10-23 | Dynamic windows open in a Perspective dock, replacing decision 24's embedded-view region: every page config defines ONE right-side dock, id `dw_Right` (400 x 860 at 1080p = 37.04 vh x 79.63 vh, display onDemand, decision 25). Window ids keep the `dw_` names; views live in `Templates/Dynamic Window/<category>/`, shared parts in `Templates/Dynamic Window/Parts/`. |
| 32 | 2026-10-24 | dw_Right dock settings (refines 31): the dock covers the right-hand section of the shell (content cover) and is always present (display visible). Each page's initial dock view is its trends overview, shown when the page loads. The `dockId` template parameter keeps its name. Open: what close does when a page has no default view (Adam to evaluate options); whether the standard states the 8.1.22 library minimum or only the 8.1.19 API floor. |
| 33 | 2026-10-24 | All design work is for a 1920 x 1080 page that scales up to 4K: a size given in px is the design-px equivalent in vh / vw. The dw_Right dock (Page Configuration size is px only) is scaled in script: `efc.ui.sizeDock` sets its size to 400 x viewport height / 1080 (37.04 vh; 800 px at 4K) through `alterDock` on every open, close and screen startup, and from a screen change script on `page.props.dimensions.viewport.height` (Ignition 8.1.7+). |
| 34 | 2026-10-25 | Every process value is historized. The Ignition UDTs get a `HistProvider` parameter (tag history provider / historian database name, empty = no history), passed down to nested instances; `Val_PV` on T_AI, T_KPI and T_Analyzer and `Val_PV` / `Val_SP` / `Out_CV` on T_PID have history enabled when `HistProvider` is set (analog deadband, on change, provider defaults otherwise). The demo UDTs (T_AI_Demo, T_PID_Demo) carry the same parameter so demo screens trend on a gateway with a historian. Prerequisite for the dock's trends overview (decision 32). |
| 35 | 2026-10-25 | Trends overview, the dock's default view (decision 32): `Templates/Dynamic Window/TrendsOverview` charts every process value on the screen, one Power Chart plot per variable type (pressure, temperature, flow, ...), stacked, 30 min default, range 5 m .. 24 h. Perspective cannot scan a page, so process-value templates register themselves: root onStartup / onShutdown and a tagPath change script call `efc.pv.register` / `unregister` / `rebind`; the registry is a gateway-memory map per `<sessionId>\|<pageId>` (parallel session.custom writes lose entries); a page message `efc.pvChanged` is only a hint. Variable type comes from the engineering unit (`efc.pv.VAR_TYPES`), ISA tag letter as tie-break for %, lengths and missing units, else Other. Templates inside windows and popups set `census` = false. Projects add the Session Shutdown event `efc.pv.purgeSession(session.props.id)`. Every dock view also carries the viewport-height change script, so screens need none (closes decision 33's per-screen step). |
